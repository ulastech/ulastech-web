# UlasTech Website (ulastech.com)

Website profil pribadi dan portal ulasan teknologi modern dengan fitur:
- Responsive Design (Tailwind CSS)
- Dashboard Admin Terintegrasi (CRUD Artikel, Kelola Pesan Kontak, Ganti Password)
- Sistem Pencarian & Filter Kategori Ulasan
- Default Admin Login:
  - **Email:** `admin@ulastech.com`
  - **Password:** `admin123`

## Cara Publish Gratis ke Domain ulastech.com:

### Opsi 1: Menggunakan Vercel (Paling Mudah)
1. Buka [Vercel.com](https://vercel.com) dan buat akun gratis.
2. Drag & drop folder ini atau hubungkan repositori GitHub Anda.
3. Klik **Deploy**.
4. Masuk ke tab **Settings > Domains** di Vercel, lalu tambahkan domain `ulastech.com`.

### Opsi 2: Menggunakan Netlify
1. Buka [Netlify.com](https://netlify.com) dan buat akun gratis.
2. Drag & drop folder yang berisi `index.html` ini ke dashboard Netlify.
3. Website langsung aktif, lalu hubungkan custom domain `ulastech.com` di menu **Domain management**.
